## ChinaSuuq Full Functionality + Polish — Implementation Plan

This plan is derived from three parallel audits: (1) mobile screens & CRUD, (2) admin mission control, (3) design & WebView performance. It is delivered in **three coordinated streams** running in parallel so every Supabase-backed workflow is testable end-to-end.

### Critical foundation (before streams)

**1. Database schema + adapter (1 new migration, 1 new view, 1 schema-bridge helper)**
- Add `apps/web/supabase/migrations/014_admin_view_layer.sql` with:
  - `admin_orders_view` (joins `orders` + `profiles` + `order_items`)
  - `admin_payments_view` (maps legacy `payment_method` strings to enum)
  - `admin_sourcing_view`, `admin_quotes_view`, `admin_shipments_view`, `admin_warehouse_view`, `admin_staff_view`, `admin_customers_view`
  - Extend enums: `order_status` (add `awaiting_payment`, `in_warehouse`, `customs`, `out_for_delivery`); `payment_status` (add `confirmed`); `sourcing_status` (add `assigned`, `quoted`, `purchased`); `shipping_status` (add `preparing`, `loaded`, `received`, `inspected`, `returned`)
  - Add missing columns: `sourcing_requests.customer_id`, `marketplace` text, `product_description`, `destination_city`, `quantity`, `product_url`, `images`, `price_cny`, `price_usd`; `quotes.request_id`, `exchange_rate`, `total_cny`; `shipments.reference`, `method`, `origin`, `destination`, `departure_date`, `estimated_arrival`, `tracking_number`; `warehouse_packages.barcode`, `photos`, `weight_kg`; `products.marketplace` text
  - `customers_view` and `settings` (key/value) tables
- RLS re-bound to the new views.

**2. Mobile schema adapter (1 new module)**
- `apps/mobile/src/lib/supabase-adapter.ts` — central place that translates local `LocalOrder` → Supabase row shape (`profile_id`, `order_number`, `subtotal`/`shipping_cost`/`total`, `address_id` via `addresses` table, etc.). Every `createOrder`, `saveSourcingCapture`, `saveAddress`, `toggleFavorite` call routed through this adapter.
- Fix `createOrder` to always include `profile_id = auth.uid()` so admin mission control can see orders.

**3. Shared constants + auth**
- Move duplicated `MARKETPLACES` array to `apps/mobile/src/lib/marketplaces.ts` (single source of truth).
- Populate `auth.user.phone` + `auth.user.city` from `getProfile()` on `loadSession`.

### Risk & mitigation

| Risk | Mitigation |
|---|---|
| New schema may take 5-10 min to apply on Supabase | Apply migration in dev project first; add rollback |
| Existing mobile data (local AsyncStorage) won't fit the new schema | Adapter maps both ways; local stays AsyncStorage until next online sync |
| RLS changes might block existing admin sessions | Test with new admin user created via seed |
| `injectedJavaScriptBeforeContentLoaded` may break if the page runs checks before our script | Wrap in `try { ... } catch`; gracefully skip |
| Webp assets require Expo SDK 54+ image pipeline | Already on 54.0.36, works |
| Admin recovery code removal might lock out current operators | Add server-side Edge Function as replacement |
| Visual polish in A6 + A7 needs design review | Use the design skill's aesthetic directions (pick one: refined minimal, soft warm, bold maximal) |
